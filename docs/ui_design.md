# UI Design

The product UI emphasizes agent traceability and evidence inspection.

## Pages

- Home
- Chat Agent
- Literature Search
- Evidence Library
- Evaluation Dashboard
- Admin / Settings

## Chat Workspace

- Left panel: session, mode, retrieval level, strictness
- Center: question input and cited answer
- Right panel: evidence cards
- Debug area: route, confidence gate, retrieval steps, latency

## Visual Principles

- Dense, readable, work-focused layout
- Evidence cards show title, PMID/DOI, journal, year, scores, and snippet
- Confidence badges make the system's uncertainty visible
- Trace IDs make backend runs inspectable
